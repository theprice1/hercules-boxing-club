# Hercules Boxing Club CIC | Digital Infrastructure & Website

A community-first, accessible web prototype built for **Hercules Boxing Club CIC** (Islington, London) to support their transition toward official **England Boxing Affiliation** and secure local authority funding.

## 🥊 Project Overview

Hercules Boxing Club is a registered Community Interest Company (CIC) dedicated to keeping session fees heavily subsidized for disadvantaged youth in Islington. This digital build was engineered from scratch to bridge the gap between their physical gym floor and national sports governance bodies.

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, Tailwind CSS (via Play CDN for rapid zero-config prototyping)
- **Interactivity:** Vanilla JavaScript (Mobile menu state management)
- **Accessibility:** Fully semantic markup with ARIA roles and screen-reader utilities (`sr-only`) designed to pass automated audits.
- **Hosting-Ready:** Configured for zero-overhead static deployment (GitHub Pages / Vercel / Netlify).
